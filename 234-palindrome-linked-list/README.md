# 234. Palindrome Linked List

Given the `head` of a singly linked list, return `true`_ if it is a __palindrome__ or _`false`_ otherwise_.

 

Example 1:**

```
Input: head = [1,2,2,1]
Output: true
```

Example 2:**

```
Input: head = [1,2]
Output: false
```

 

**Constraints:**

	
- The number of nodes in the list is in the range `[1, 105]`.
